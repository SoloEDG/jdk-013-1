# 潮汐之间

安装：`npm install`

本地启动：`npm run dev`

类型检查：`npm run typecheck`；生产构建：`npm run build`。

Docker 启动：`docker compose up --build`，访问 http://localhost:8133 。

## 离线展映包

顶部导航「离线展映」→「制作新的展映包」：

1. 勾选要带走的章节。相同的影像/全景/访谈只下一次（多章节共用）。
2. 「检查素材」列出缺失项、缺失体积、整包体积与本机可用空间，已有缓存单独标出。
3. 「开始制作」后可以离开此页继续观看、进入访谈、写笔记。
4. 任务完成时要求明确选择笔记范围（仅所选章节 / 本部全部 / 不带）；手记按该范围复制快照，
   不会混入之后打开的其他片子。
5. 展映包保存的是开始制作时的内容版本快照，之后更新内容不影响已完成的包。

失败处理：任务停在「部分素材失败」，只重试缺失部分；可显式保存为「不完整」包，
不完整包不会被显示成已完成。已有的可用包不会因空间不足被删除或覆盖。

断网使用：制作完成并至少联网打开过一次后，Service Worker 会缓存应用外壳；
断网重新打开站点即进入离线展映入口，可播放章节、进入访谈、保存探索手记。
必要时执行 `npm run build` 后用 `npm run preview`（或 Docker）验证离线行为，
`npm run dev` 不注册 Service Worker。
